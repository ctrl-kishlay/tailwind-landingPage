# FlowApp Landing Page

A simple responsive SaaS landing page built using HTML and Tailwind CSS.

## Features

-   Responsive navbar
-   Hero section
-   Features section
-   Testimonials
-   Call to Action section
-   Footer
-   Glassmorphism UI
-   Gradient buttons
-   Responsive design
-   Simple animations
-   Mobile navigation menu

## Built With

-   HTML5
-   Tailwind CSS
-   JavaScript

## How to Run

1.  Clone or download the project.
2.  Install the project dependencies.
3.  Run the Tailwind watcher.
4.  Open `index.html` in your browser.

``` bash
npx @tailwindcss/cli -i ./input.css -o ./output.css --watch
```
